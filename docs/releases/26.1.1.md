# SwiftSimSlim 26.1.1

Version 26.1.1, build 5.

## Changes

- New **Device Management** category for `com.apple.remotemanagementd`, `com.apple.RemoteManagementAgent`, and `com.apple.managedassetsd`.
- **Other Background Services** now includes App Clips (`com.apple.ClipServices.clipserviced`) and accessibility asset downloads (`com.apple.accessibility.axassetsd`).
- Full Slim includes all five additions. Retaining a category or individual service excludes it from disabling; existing unmanaged overrides remain intact.
- Updated service explanations and approximate category memory estimates from [simslim #66](https://github.com/MobAI-App/simslim/pull/66), with regression coverage for upgrading an older profile and restoring retained services.

## Verification and limits

Build and targeted test results for the final release commit are recorded in the GitHub release. Tests use synthetic simulator responses and temporary files. New service compatibility, RAM savings, and UI appearance have not been verified on a real simulator for this release.

Disabling the new services affects declarative device management workflows, App Clips, and accessibility asset downloads. Core `profiled` and `mdmd` services remain outside the allowlist, and required compatibility services stay enabled. Disk cleanup rules are unchanged. Automatic preparation before first boot is not included.

GitHub provides source archives; build with the SwiftSimSlim scheme and My Mac destination.
