# SwiftSimSlim 26.1

Version 26.1, build 4. This source release includes the updated simulator-and-RAM icon and screenshots in the README.

The icon uses a fixed iPhone template, a larger green RAM module, and a black background. Separate foreground layers preserve transparency and device proportions. The README icon matches the compiled app icon.

## New features

- **Full Slim & Clean:** one confirmed operation saves the original service state, applies Full Slim, and cleans all supported categories while retaining apps, Documents, photos, and app settings.
- **Apps & Data:** inspect developer-installed apps sorted by size, with bundle, Documents, other private data, and total sizes. Uninstall an app or selectively clear its private data through a separate confirmation.
- **Complete disk breakdown:** account for both cleanable and retained storage. A fixed Disk Cleanup bar groups the estimate, re-analysis, cleanup, and last successful cleanup result.
- **Optional system cleanup:** wallpaper/poster snapshot caches, known Siri/speech assets, downloaded system models, and intelligence history/indexes. Original wallpapers, custom voices, unknown catalogs, and durable content remain protected.
- **Profiles without restart:** opt-in live changes on booted simulators, with saved-state recovery, loaded-job verification, and an explicit restart action when some jobs cannot load yet.

## Fixes and interface changes

- Disk analysis classifies files in a single accounting walk, supports cancellation, and tolerates transient files disappearing during the scan.
- Selecting devices or completing analysis no longer reorders cleanup categories or changes analysis-row height. The header remains below the toolbar; toolbar groups stay left, center, and right.
- Destructive confirmations use red, bold buttons instead of requiring typed words.
- Transient launchd read failures use bounded retries; permanent errors and malformed state remain errors.
- Search service descriptions explain the effect on Recents in Files and document pickers. Regression coverage protects packaged app resources during cache/log/temp cleanup.

## Verification and limits

Ordinary tests use synthetic service responses and temporary files. The UI test uses seven synthetic simulators, three window sizes, and sample app containers; it reviews and cancels deletion/combined-cleanup confirmations. Screenshots show these test data. Release verification results are recorded in the GitHub release.

This release does not establish restart-free performance or complete app compatibility on every iOS runtime. Optional downloads and indexes can return; Full Slim does not mean zero RAM use. File deletion is permanent, and service-state backups are not file backups. Shared runtimes and required compatibility services remain protected.

Like previous releases, GitHub provides source archives; build the app in Xcode with the SwiftSimSlim scheme and My Mac destination.
