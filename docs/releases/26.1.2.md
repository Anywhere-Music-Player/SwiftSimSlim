# SwiftSimSlim 26.1.2

Version 26.1.2, build 8.

## Changes

- **Clean Wallpaper Cache…** directly opens a confirmation for generated wallpaper caches. Cleanup now recognizes accumulated Home Screen `RuntimeSnapshot-…-home.atx` textures in known poster layouts. Wallpaper originals, configuration, unrecognized files, installed apps, and their durable data are kept.
- **Disable Wallpapers…** is a separate, explicit reset: disable only the allowlisted PosterBoard service, shut down, remove the wallpaper store, then restart to verify the service remains disabled. The background becomes black. Apps, app documents, preferences, app groups, photos, and shared runtimes are outside this reset.
- Wallpaper reset revalidates the exact simulator/device set and data path before deletion, rejects symlink redirects and special files, and restores the requested boot state after success or failure. A service backup is saved before changing an enabled PosterBoard override.
- The toolbar now opens **Full Slim & Clean** directly, without a single-item Optimize menu.
- **Full Slim & Clean** now has compact checkboxes for Full Slim and each cleanup category, all selected initially. Unchecked steps are skipped; an empty selection cannot run. The confirmation can be resized, with a scrolling list and accessible action buttons at smaller sizes.
- Updated README feature descriptions and screenshots of the running app.

## Verification and limits

Final-commit build and targeted test counts are recorded in the GitHub release. Unit tests use synthetic simulator responses and temporary files. UI tests cover confirmation/cancellation, preservation of unrelated files, checkbox defaults, and actual mouse-driven resizing.

The wallpaper mode was separately exercised with the actual backend on a disposable iPhone 18 Pro simulator running iOS 27.2. Across three boot cycles, the test app launched, app-bundle hashes and control document/preferences/database/media bytes remained unchanged, and the wallpaper store did not return. A repeated operation on a stopped simulator restored Shutdown. An additional disposable run checked the settled black Home Screen. All disposable devices were deleted afterward. These are short acceptance checks, not a guarantee for other runtimes or indefinite prevention of regrowth.

Disabling PosterBoard alone did not prevent snapshot accumulation in the observed runtime. The explicit reset also removes wallpaper originals and Home/Lock Screen configuration. Wallpaper customization is unavailable while disabled. Restoring services may recreate defaults; a service backup cannot restore deleted custom wallpapers. This reset is never automatically included in Full Slim & Clean or routine cache cleanup.

Native fitted sheet sizing is used on macOS 15 and later. The macOS 14 layout remains compatible but has not had separate runtime verification for this release.

GitHub provides source archives; no prebuilt app is attached. Build with the SwiftSimSlim scheme and My Mac destination.
